Automations are recurring tasks. Each run starts a new conversation with the prompt you saved.

## Create from scratch

<Steps>
  <Step title="Open Automations">
    On New Chat, click **Automations**, then **Create from scratch**. You can also navigate to **Automations** on the sidebar and click **\+ Create**.
  </Step>
  <Step title="Name it and write the prompt">
    Enter a name and the instructions askROI should follow each time it runs.
  </Step>
  <Step title="Set the schedule">
    Choose when it should run. The default is **Daily at 9:00 AM** in your timezone (for example Los Angeles / Pacific). Use **Advanced** if you need a different time.
  </Step>
  <Step title="Create">
    Click **Create automation**. You should see a confirmation, then a detail page with status **Active**, the next run time, and **Run now**.
  </Step>
</Steps>

## Describe it in chat

From the Automations panel in a chat page, you can also click **Describe it in chat**. The prompt box is filled with a request to create an automation. Edit it, then send. Review the draft before you save a real schedule.

## Find and stop an automation

Open [askroi.com/automations](https://www.askroi.com/automations) to see name, schedule, next run, last run, and status. Under Your Automations, open an automation by clicking on it to edit, run it now, or turn it off.
