The Library is where askROI keeps files you upload or generate, they are automatically added to your library. Projects can pull from Library when you add project files.

## Open Library

<Steps>
  <Step title="Click Library">
    In the left menu, click **Library** (the books icon).
  </Step>
  <Step title="Browse, download and manage files">
    Click a file to open it. You can download the file to your computer or phone.

    You can also add files to different folders to keep things organized.

     
  </Step>
  <Step title="Use a file in a Chat or Project (optional)">
    Open **New Chat** and click the **\+** icon in the chat window** **→ **Add from Library**.

    Open a **Project**, click **Project Files**, then **Add from library**. Choose the file and add it to that Project.
  </Step>
</Steps>
