askROI lets you bring your own documents into the conversation. Upload a file and immediately start asking questions about it — extract key data, request a summary, compare multiple documents, or have askROI draft a follow-up based on what it finds. Your files stay in context so the AI always has the full picture as the conversation continues.

## Supported File Types

askROI accepts a wide range of common document formats, including:

- **PDFs** — reports, research papers, contracts, presentations
- **Spreadsheets** — Excel (`.xlsx`, `.xls`) and CSV files
- **Word documents** — `.docx` and `.doc` files
- **Plain text** — `.txt` and `.md` files
- **Other common formats** — additional file types may be supported; if your format isn't recognized, try converting it to PDF

## Uploading a File

<Steps>
  <Step title="Open the attach menu">
    In the chat input bar, click the **paperclip** (attach) icon on the left side of the text field.
  </Step>
  <Step title="Select your file">
    Choose a file from your device. On mobile, you can also pick directly from your photo library or cloud storage. The file will upload and a preview thumbnail will appear in the chat input.
  </Step>
  <Step title="Ask your question">
    Type your question or instruction in the chat field — for example, "Summarize the key findings" or "What is the total revenue in Q3?" — then press **Send**. askROI reads your file and responds immediately.
  </Step>
</Steps>

## What You Can Do with Uploaded Files

Once a file is uploaded, you can put it to work in several ways:

- **Summarize** — get a concise overview of a long report or document in seconds
- **Extract key data** — pull out specific figures, dates, names, or tables without reading the whole file
- **Answer questions** — ask anything about the document's contents and get a direct, cited answer
- **Compare documents** — upload two or more files and ask askROI to highlight differences or similarities
- **Draft follow-ups** — have askROI write a response, memo, or report based on what it found in your files

## Files in Projects

When you upload a file inside a [Project](/features/projects), it stays attached to that workspace across all conversations. You don't have to re-upload the document each time — askROI remembers it and can reference it whenever you return to the Project. This is ideal for ongoing work like tracking a research topic, managing a client engagement, or collaborating on a long-form document.
