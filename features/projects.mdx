Projects give your AI work a home. Instead of scattered chats and re-uploading the same files every session, a Project bundles everything together — your documents, conversation history, and the context the AI needs to stay on track. Open a Project and askROI already knows what you're working on.

## What Is a Project?

A Project is a dedicated workspace inside askROI that keeps three things in one place: your **files**, your **chat history**, and your **AI context**. When you chat inside a Project, the AI has direct access to every file you've added and every conversation you've had there — so it never loses the thread.

This persistent context means you can start a new chat in a Project and continue a line of thinking from days ago without re-explaining anything. Projects are ideal for ongoing research, long-form writing, client work, or any task that spans multiple sessions.

## Creating a Project

<Steps>
  <Step title="Open the sidebar">
    Click the sidebar toggle (or swipe right on mobile) to reveal the navigation panel.
  </Step>
  <Step title="Click New Project">
    Select **New Project** near the top of the sidebar. A project creation dialog will appear.
  </Step>
  <Step title="Name your Project">
    Enter a descriptive name that reflects the work — for example, "Q3 Market Research" or "Website Redesign Copy." A clear name makes it easy to find later.
  </Step>
  <Step title="Add files or context">
    Upload any relevant documents, PDFs, or spreadsheets right away, or add a brief description of the project's purpose so the AI starts with the right framing. You can always add more files later.
  </Step>
</Steps>

Your new Project appears in the sidebar immediately and is ready for your first chat.

## Working Inside a Project

Every chat you start inside a Project automatically has access to all the files and history stored there. You don't need to re-attach documents or re-explain background — askROI reads the Project context before it responds.

As you work, the AI learns the vocabulary, goals, and nuances specific to that Project. References you made in an earlier session carry forward, so conversations feel continuous rather than isolated. You can also jump between multiple Projects without losing context in any of them.

<Tip>
Pin your most active Projects to the top of the sidebar for fast access. Use descriptive names so you can find the right workspace at a glance.
</Tip>

## Managing Files in a Project

To add files to a Project, open the Project and click **Add Files** (or drag and drop directly into the file panel). askROI supports:

- **PDFs** — research papers, contracts, reports
- **Spreadsheets** — CSV, Excel, and Google Sheets exports
- **Documents** — Word docs, plain text, markdown files

Files are indexed automatically after upload, so the AI can reference specific passages, tables, or figures the moment you ask. You can rename, reorder, or remove files from the file panel at any time without affecting your chat history.

</Note>
